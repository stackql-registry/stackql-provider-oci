Gets the logs for a work request.&lt;br /&gt;

```sql
SELECT
message,
timestamp
FROM oci.identity.tagging_work_request_logs
WHERE workRequestId = '{{ workRequestId }}' -- required
AND region = '{{ region }}' -- required
AND page = '{{ page }}'
AND limit = '{{ limit }}'
;
```
