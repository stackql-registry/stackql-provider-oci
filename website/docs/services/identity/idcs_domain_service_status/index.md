Internal API to get the IDCS domain service status, value being true specifies secondary domain can be created in&lt;br /&gt;region being build , value being false signifies otherwise&lt;br /&gt;

```sql
SELECT
isIdcsDomainServiceServiceAvailable
FROM oci.identity.idcs_domain_service_status
WHERE region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
