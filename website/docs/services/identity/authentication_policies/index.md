## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Gets the authentication policy for the given tenancy. You must specify your tenant's OCID as the value for&lt;br /&gt;the compartment ID (remember that the tenancy is simply the root compartment).&lt;br /&gt;

```sql
SELECT
compartmentId,
networkPolicy,
passwordPolicy
FROM oci.identity.authentication_policies
WHERE compartmentId = '{{ compartmentId }}' -- required
AND region = '{{ region }}' -- required
;
```
</TabItem>
</Tabs>


## `UPDATE` examples

<Tabs
    defaultValue="update"
    values={[
        { label: 'update', value: 'update' }
    ]}
>
<TabItem value="update">

Updates authentication policy for the specified tenancy.&lt;br /&gt;

```sql
UPDATE oci.identity.authentication_policies
SET 
networkPolicy = '{{ networkPolicy }}',
passwordPolicy = '{{ passwordPolicy }}'
WHERE 
compartmentId = '{{ compartmentId }}' --required
AND region = '{{ region }}' --required
AND if-match = '{{ if-match}}'
RETURNING
compartmentId,
networkPolicy,
passwordPolicy;
```
</TabItem>
