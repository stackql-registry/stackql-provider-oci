Deletes the specified NAT gateway. The NAT gateway does not have to be disabled, but there&lt;br /&gt;must not be a route rule that lists the NAT gateway as a target.&lt;br /&gt;&lt;br /&gt;This is an asynchronous operation. The NAT gateway's `lifecycleState` will change to&lt;br /&gt;TERMINATING temporarily until the NAT gateway is completely removed.&lt;br /&gt;

```sql
DELETE FROM oci.network.nat_gateways
WHERE natGatewayId = '{{ natGatewayId }}' --required
AND region = '{{ region }}' --required
AND if-match = '{{ if-match }}'
;
```
