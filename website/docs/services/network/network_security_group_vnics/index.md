Lists the VNICs in the specified network security group.&lt;br /&gt;

```sql
SELECT
resourceId,
timeAssociated,
vnicId
FROM oci.network.network_security_group_vnics
WHERE networkSecurityGroupId = '{{ networkSecurityGroupId }}' -- required
AND region = '{{ region }}' -- required
AND limit = '{{ limit }}'
AND page = '{{ page }}'
AND sortBy = '{{ sortBy }}'
AND sortOrder = '{{ sortOrder }}'
;
```
