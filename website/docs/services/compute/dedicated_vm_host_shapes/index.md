## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="list">

Lists the shapes that can be used to launch a dedicated virtual machine host within the specified compartment.&lt;br /&gt;

```sql
SELECT
availabilityDomain,
capacityConfigs,
dedicatedVmHostShape
FROM oci.compute.dedicated_vm_host_shapes
WHERE compartmentId = '{{ compartmentId }}' -- required
AND region = '{{ region }}' -- required
AND availabilityDomain = '{{ availabilityDomain }}'
AND instanceShapeName = '{{ instanceShapeName }}'
AND limit = '{{ limit }}'
AND page = '{{ page }}'
AND opc-request-id = '{{ opc-request-id }}'
;
```
