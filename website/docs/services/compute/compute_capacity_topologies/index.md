<TabItem value="create">

Creates a new compute capacity topology in the specified compartment and availability domain.&lt;br /&gt;&lt;br /&gt;Compute capacity topologies provide the RDMA network topology of your bare metal hosts so that you can launch&lt;br /&gt;instances on your bare metal hosts with targeted network locations.&lt;br /&gt;&lt;br /&gt;Compute capacity topologies report the health status of your bare metal hosts.&lt;br /&gt;

```sql
INSERT INTO oci.compute.compute_capacity_topologies (
availabilityDomain,
capacitySource,
compartmentId,
definedTags,
displayName,
freeformTags,
region,
opc-request-id,
opc-retry-token
)
SELECT 
'{{ availabilityDomain }}' /* required */,
'{{ capacitySource }}' /* required */,
'{{ compartmentId }}' /* required */,
'{{ definedTags }}',
'{{ displayName }}',
'{{ freeformTags }}',
'{{ region }}',
'{{ opc-request-id }}',
'{{ opc-retry-token }}'
RETURNING
id,
availabilityDomain,
capacitySource,
compartmentId,
definedTags,
displayName,
freeformTags,
lifecycleState,
timeCreated,
timeUpdated
;
```
