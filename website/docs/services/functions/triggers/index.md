Returns a list of Triggers.&lt;br /&gt;

```sql
SELECT
name
FROM oci.functions.triggers
WHERE region = '{{ region }}' -- required
AND name = '{{ name }}'
AND limit = '{{ limit }}'
AND page = '{{ page }}'
AND sortOrder = '{{ sortOrder }}'
AND opc-request-id = '{{ opc-request-id }}'
;
```
