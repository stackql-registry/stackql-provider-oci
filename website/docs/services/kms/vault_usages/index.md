Gets the count of keys and key versions in the specified vault to calculate usage against service limits.&lt;br /&gt;

```sql
SELECT
keyCount,
keyVersionCount,
softwareKeyCount,
softwareKeyVersionCount
FROM oci.kms.vault_usages
WHERE vaultId = '{{ vaultId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
