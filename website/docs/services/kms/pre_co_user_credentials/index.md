Retrieves Pre Crypto Officer user credentials for the specified HSM cluster.&lt;br /&gt;

```sql
SELECT
password,
username
FROM oci.kms.pre_co_user_credentials
WHERE hsmClusterId = '{{ hsmClusterId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
AND opc-retry-token = '{{ opc-retry-token }}'
;
```
