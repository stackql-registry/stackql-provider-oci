## `SELECT` examples

<Tabs
    defaultValue="list"
    values={[

Lists the logs for a work request.&lt;br /&gt;

```sql
SELECT
message,
timestamp
FROM oci.streaming.work_request_logs
WHERE workRequestId = '{{ workRequestId }}' -- required
AND region = '{{ region }}' -- required
AND page = '{{ page }}'
AND limit = '{{ limit }}'
AND sortOrder = '{{ sortOrder }}'
AND sortBy = '{{ sortBy }}'
AND opc-request-id = '{{ opc-request-id }}'
;
```
