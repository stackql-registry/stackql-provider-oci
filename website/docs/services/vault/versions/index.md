<TabItem value="schedule_secret_version_deletion">

Schedules the deletion of the specified secret version. This deletes it after the specified retention period ends. You can only&lt;br /&gt;delete a secret version if the secret version rotation state is marked as `DEPRECATED`.&lt;br /&gt;

```sql
EXEC oci.vault.versions.schedule_secret_version_deletion 
@secretId='{{ secretId }}' --required, 
@secretVersionNumber='{{ secretVersionNumber }}' --required, 
@region='{{ region }}' --required, 
@if-match='{{ if-match }}', 
@opc-request-id='{{ opc-request-id }}' 
@@json=
'{
"timeOfDeletion": "{{ timeOfDeletion }}"
}'
;
```
</TabItem>
