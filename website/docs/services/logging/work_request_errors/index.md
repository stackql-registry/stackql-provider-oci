Return a list of errors for a given work request.&lt;br /&gt;

```sql
SELECT
code,
message,
timestamp
FROM oci.logging.work_request_errors
WHERE workRequestId = '{{ workRequestId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
AND page = '{{ page }}'
AND limit = '{{ limit }}'
;
```
