## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' },
        { label: 'list', value: 'list' }
    ]}
>
<TabItem value="get">

Gets a CostAnomalyEvent by the identifier.

```sql
SELECT
id,
compartmentId,
costImpact,
costMonitorId,
costMonitorName,
costVariancePercentage,
definedTags,
feedbackResponse,
freeformTags,
lifecycleState,
rootCauseDetail,
systemTags,
targetResourceFilter,
timeAnomalyEventDate,
timeCreated,
timeUpdated
FROM oci.budgets.cost_anomaly_events
WHERE costAnomalyEventId = '{{ costAnomalyEventId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
</TabItem>
<TabItem value="list">

Gets a list of Cost Anomaly Event in a compartment.&lt;br /&gt;

```sql
SELECT
id,
compartmentId,
costImpact,
costMonitorId,
costMonitorName,
costVariancePercentage,
definedTags,
freeformTags,
lifecycleState,
systemTags,
targetResourceFilter,
timeAnomalyEventDate
FROM oci.budgets.cost_anomaly_events
WHERE compartmentId = '{{ compartmentId }}' -- required
AND costAnomalyMonitorId = '{{ costAnomalyMonitorId }}' -- required
AND timeAnomalyEventStartDate = '{{ timeAnomalyEventStartDate }}' -- required
AND timeAnomalyEventEndDate = '{{ timeAnomalyEventEndDate }}' -- required
AND region = '{{ region }}' -- required
AND costImpact = '{{ costImpact }}' -- required
AND limit = '{{ limit }}'
AND page = '{{ page }}'
AND sortOrder = '{{ sortOrder }}'
AND sortBy = '{{ sortBy }}'
AND name = '{{ name }}'
AND targetTenantId = '{{ targetTenantId }}'
AND opc-request-id = '{{ opc-request-id }}'
;
```

feedbackResponse = '{{ feedbackResponse }}',
