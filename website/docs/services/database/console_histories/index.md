<Tabs

<TabItem value="get">

Gets information about the specified database node console history.&lt;br /&gt;

```sql
SELECT
id,
compartmentId,
dbNodeId,
definedTags,
displayName,
freeformTags,
lifecycleDetails,
lifecycleState,
timeCreated
FROM oci.database.console_histories
WHERE dbNodeId = '{{ dbNodeId }}' -- required
AND consoleHistoryId = '{{ consoleHistoryId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
</TabItem>

AND opc-request-id = '{{ opc-request-id }}'
