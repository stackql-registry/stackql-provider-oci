Retrieves the specified database node console history contents upto a megabyte.&lt;br /&gt;

```sql
SELECT
*
FROM oci.database.console_history_contents
WHERE dbNodeId = '{{ dbNodeId }}' -- required
AND consoleHistoryId = '{{ consoleHistoryId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
