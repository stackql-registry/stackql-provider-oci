## `SELECT` examples

<Tabs
    defaultValue="get"
    values={[
        { label: 'get', value: 'get' }
    ]}
>
<TabItem value="get">

Gets the Autonomous AI Database regional wallet details.&lt;br /&gt;

```sql
SELECT
lifecycleState,
timeDownloaded,
timeRotated
FROM oci.database.autonomous_database_regional_wallets
WHERE region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
</TabItem>
</Tabs>
