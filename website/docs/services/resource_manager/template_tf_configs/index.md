Returns the Terraform configuration file in zip format for the specified template.&lt;br /&gt;Returns an error if no zip file is found.&lt;br /&gt;For more information, see&lt;br /&gt;&#91;Getting a Private Template's Terraform Configuration&#93;(/iaas/Content/ResourceManager/Tasks/get-template-tf-config.htm).&lt;br /&gt;

```sql
SELECT
*
FROM oci.resource_manager.template_tf_configs
WHERE templateId = '{{ templateId }}' -- required
AND region = '{{ region }}' -- required
AND opc-request-id = '{{ opc-request-id }}'
;
```
